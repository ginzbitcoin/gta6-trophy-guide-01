Panduan dan tracker offline 55 trofi PS5 GTA VI: guide lengkap, roadmap 7 tahap, dan 5 trofi missable. Desain gelap neon pink dan teal khas Vice City dan Leonida, dengan banner besar dan icon SVG untuk tiap trofi.

## Isi

- 55 trofi: 1 platinum (Vice Got a Price!), 2 gold, 6 silver, 46 bronze
- 5 trofi missable: Catch Me If You Can, Capital Offense, Actions Speak Louder, Bad Luck I Guess, The Truth Is Out There
- 3 tab: Guide dan tracker, Roadmap 7 tahap, Missable
- Tracker di localStorage, export dan import JSON, cari, filter, mode spoiler-free, deep-link hash

## Cara pakai

Buka `app/index.html` di browser, atau jalankan server lokal:

```sh
node serve.ts
```

Lalu buka http://127.0.0.1:8080
